# DecodeLabs Data Analyst Portfolio – Projects 1–4

Welcome to my DecodeLabs Data Analyst Project Portfolio.

This repository contains four practical data analytics projects completed as part of my data analytics learning journey with DecodeLabs. The goal of these projects was not only to analyze data, but also to turn raw datasets into meaningful insights that can support business understanding, decision-making, and 
performance improvement.
